# SupplyMatch

SupplyMatch es una plataforma digital diseñada para conectar empresas, emprendedores y PyMEs con proveedores confiables.

## Objetivo

Facilitar la búsqueda y conexión con proveedores de manera rápida, segura y eficiente.

## Servicios

- Búsqueda de proveedores confiables
- Conexión entre empresas y proveedores
- Membresías para diferentes necesidades empresariales

##  utilizadas

- HTML
- CSS
- JavaScript

## Proyecto académico

Proyecto desarrollado para la Licenciatura en Comercio y Negocios Internacionales.
